# Experiments

This directory stores lightweight experiment metadata, figures, and report artifacts.

- `results/`: CSV/JSON/Markdown summaries generated from real runs.
- `figures/`: exported dashboard figures.
- `reports/`: generated experiment reports, model cards, and data cards.

Large model weights, raw datasets, and prediction arrays should remain outside Git history.
Synthetic quick-start experiments are useful for smoke tests only and must be labeled as synthetic.
