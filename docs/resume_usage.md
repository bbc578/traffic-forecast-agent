# Resume Usage

## If You Only Ran Synthetic Data

Use wording like:

> Built a smart traffic forecasting engineering demo using synthetic traffic sensor data to validate
> data preprocessing, model training, congestion-risk analysis, agent querying, and visualization workflow.

Do not report synthetic metrics as real traffic performance.

## If You Ran METR-LA / PEMS-BAY

Use wording like:

> Built an urban traffic speed forecasting and congestion-risk analysis system on METR-LA / PEMS-BAY,
> comparing LastValue, HistoricalAverage, LSTM, GRU, STGCNImproved, and GraphWaveNetLite across horizons,
> nodes, time-of-day buckets, and graph-structure ablations.

Fill in only the metrics generated by your own runs.

## Do Not Write

- “Achieved SOTA.”
- “Industrial-grade deployment.”
- “Can be used directly for city traffic control.”
- Fake improvement percentages.
