# Data

The default demo uses `data/sample/synthetic_traffic.npz`, generated by:

```bash
python -m traffic_agent.data.generate_synthetic --output data/sample/synthetic_traffic.npz
```

This synthetic demo data is only for workflow demonstration. It does not represent real city traffic and should not be used to claim real-world forecasting performance.

Expected `.npz` schema:

- `data`: `[T, N, F]`
- `adjacency`: `[N, N]`
- `feature_names`: includes `speed` and `flow`
- `node_ids`: `[N]`
- `is_synthetic_data`: boolean metadata when available
